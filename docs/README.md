## 🚀 Inicio Rápido

```bash
# Instalar dependencias
pnpm install

# Iniciar servidor de desarrollo
pnpm dev

# Build para producción
pnpm build
```

## 🎮 Cómo Jugar

1. Ve a la página de inicio
2. Lee las reglas
3. Configura los equipos en Setup
4. Elige modo Alpha o Beta
5. ¡A jugar!

## 🛠️ Comandos Útiles

| Comando | Descripción |
|---------|-------------|
| `pnpm dev` | Inicia servidor de desarrollo |
| `pnpm build` | Compila para producción |
| `pnpm preview` | Previsualiza build |
| `pnpm astro --help` | Ayuda de Astro CLI |

## 📊 Visualizar Diagramas

Todos los diagramas están en formato **Mermaid**. Puedes:

1. **Ver en VS Code**: Abre cualquier archivo `.md` con diagrama
2. **Exportar a imagen**: Copia el código en [mermaid.live](https://mermaid.live) y exporta como PNG/SVG
